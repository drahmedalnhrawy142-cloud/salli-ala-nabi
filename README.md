# صلي على النبي ﷺ

واجهة عربية RTL أولية لمنصة تبادل مفاتيح تحدي نسك، مبنية باستخدام Next.js وTypeScript وTailwind CSS.

## التشغيل المحلي

يتطلب Node.js 20.9 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000. لم تُربط قاعدة البيانات في هذه المرحلة؛ إجراءات تبادل المفاتيح والإحصائيات معروضة بوضوح على أنها غير مفعّلة، ولا تُحفظ البيانات المدخلة.

## البناء

```bash
npm run build
```

## معاينة على الهاتف

1. شغّل الخادم المحلي باستخدام `npm run dev`.
2. تأكد أن الهاتف والكمبيوتر متصلان بشبكة Wi-Fi نفسها.
3. اعرف عنوان IP المحلي للكمبيوتر، ثم افتح على الهاتف `http://<عنوان-IP>:3000`.
4. إذا منع جدار الحماية الاتصال، اسمح باتصالات Node.js على الشبكة المحلية. ويمكن استخدام معاينة نشر مؤقتة من فرع الواجهة عند توفر إعدادات الاستضافة.
